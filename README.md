# Coding Interview Vault

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

My interview prep notes and practice code. Right now it covers problem solving in Ruby and JavaScript, Ruby on Rails, React, and short refreshers on what changed in recent versions of Ruby, Rails and JavaScript.

## Start here

1. 👉 **[ROADMAP.md](ROADMAP.md)**: the checklist of everything to learn for a Rails developer role, from junior to mid level, with detailed checklists for [Ruby](roadmap/ruby.md), [Rails](roadmap/rails.md), [JavaScript](roadmap/javascript.md) and [React](roadmap/react.md).
2. 🎯 **[interview/](interview/)**: how hiring works ([guide](interview/README.md)) and a [question bank with answers](interview/questions.md).

## What's inside

| Folder | What it holds |
|---|---|
| [`roadmap/`](roadmap/) | Detailed topic checklists for Ruby, Rails, JavaScript and React |
| [`interview/`](interview/) | Interview process guide, salary and level tips, question bank |
| [`problem-solving/`](problem-solving/) | Algorithms, data structures and coding problems, solved in [Ruby](problem-solving/ruby/) and [JavaScript](problem-solving/javascript/) |
| [`rails/`](rails/) | Two Rails practice projects: a **full-stack Hotwire app** (ERB, Turbo Frames, Turbo Streams, Stimulus) and an **API-only app** used by a React frontend |
| [`react/`](react/) | React topics from basics to advanced, to learn or revise, plus the **frontend for the Rails API** |
| [`refreshers/`](refreshers/) | Short notes on modern [Ruby](refreshers/ruby.md), [Rails](refreshers/rails.md) and [JavaScript](refreshers/javascript.md) |

## Running the code

```bash
# Ruby solutions
ruby problem-solving/ruby/merge_sort.rb

# JavaScript solutions
node problem-solving/javascript/<file>.js
```

Each project under `rails/` and `react/` has its own README with setup steps.
